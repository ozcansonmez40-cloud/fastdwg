# Contributing

**FastDWG does not accept external contributions.**

This repository is published to satisfy the source-availability requirements of
the GNU GPL v3 (the app bundles GNU LibreDWG). It is not a community project:

- Pull requests will be closed without being merged.
- Issues, discussions and feature requests are not monitored here.
- No technical support is provided through this repository or by email.

## Why no contributions?

All application code (everything outside `third_party/`) has a single author
and copyright holder. Keeping it that way preserves the author's right to
relicense future versions of the application code — for example if a future
release replaces LibreDWG with a commercially licensed DWG engine. Accepting
outside code would make every contributor a co-copyright-holder and remove
that flexibility.

You are of course free to fork this repository and modify it under the terms
of the GPL v3 (see `LICENSE`), subject to the trademark note in `README.md`.
